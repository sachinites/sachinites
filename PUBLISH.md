# Publish your GitHub profile

1. Create a **public repository named exactly `sachinites`** (same as your GitHub username).
2. Upload `README.md` to the repository root.
3. Upload `header.svg` to the root too.
4. Commit the changes. GitHub will display the README on your profile.

To display the header image, add this near the top of README:
`![Profile header](header.svg)`

Review project names and social links before publishing. Stats cards are hosted by third-party services and may occasionally be unavailable.
